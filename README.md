# TSA1 – CodeIgniter Multi-Page Website

By Franz Matthew Quevedo

A CodeIgniter 4 project demonstrating MVC architecture, routing, and database-backed pages.

## Live Website
https://tsa1quevedo.gamer.gd/

## Pages
- Home: Displays today's tasks
- Tasks: Displays the task list
- Profile: Displays user information
- About: Provides information about the website

## Technologies
- PHP and CodeIgniter 4
- MySQL
- HTML and CSS
- InfinityFree hosting

## Local Setup
1. Download or clone this repository.
2. Run `composer install` to install dependencies.
3. Create a MySQL database and import `pos_db.sql`.
4. Create a `.env` file with your local database credentials and base URL.
5. Configure your web server to serve the `public` folder.

## Configuration
The `.env` file, Composer dependencies, and runtime logs are excluded from Git. Configure database credentials separately for each environment.
